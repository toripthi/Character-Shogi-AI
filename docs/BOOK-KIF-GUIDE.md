# 定跡KIFの書き方（人間用）

定跡は、棋譜ソフトで指して `.kif` で保存します。細かい書式にこだわる必要はありません。**守るのは「先頭にメタ行を足す」「平手の本譜だけ」の2点**です。

- 決定の理由：`DECISIONS.md` の D-021（KIFを入力にする）、D-022（合流）、D-023（重みの合算）
- 実装の仕様：`PHASE4-INSTRUCTIONS.md` の 4-1「KIFからの取り込み」

---

## 1. 流れ

1. 棋譜ソフトで手順を指して `.kif` で保存する
2. テキストエディタで開き、**先頭にメタ行**（下の §2）を足す
3. `data/book/kif-src/` に置く
4. 取り込みツールで `data/book/lines/` に変換し、ビルドする
   - 予定のコマンド：`node scripts/import-kif.js --all` → `node scripts/build-book.js`
   - ビルドが、全手の合法性と、最後の局面（出口）を検査する。警告が出たら §5 を見る

---

## 2. メタ行（ファイルの先頭に書く）

```
# id: user-ibisha-1
# tags: ibisha
# side: black
# weight: 10
手合割：平手
手数----指手---------消費時間--
   1 ７六歩(77)   ( 0:00/00:00:00)
   2 ３四歩(33)   ( 0:00/00:00:00)
   （以下、手順）
```

| 行 | 意味 | 省略したら |
|---|---|---|
| `id` | ラインの名前。ほかと重ならない英数字（`-` 可） | ファイル名 |
| `tags` | 戦法タグ。カンマ区切り。今あるのは `ibisha` と `furibisha` | タグなし（誰も使わない） |
| `side` | どちらの色の手を候補にするか。`black` / `white` / `both` | **エラー（必須）** |
| `weight` | 重み（その手の選ばれやすさ）。整数 | 1 |
| `personaWeights` | キャラ別の重み。`seme=5, mamori=1` の形 | 指定なし |
| `trap` | ハメ手対策用。4-3 まで空のまま | 空 |

- `:` は半角でも全角（`：`）でも構いません
- `:` を含まない `#` の行は、メモとして無視されます（日本語のメモを書いてよい）

### `tags` の効き方
- **タグ付きのラインは、そのタグを持つ戦法のキャラだけが使います。** `ibisha` のラインは居飛車党だけ、`furibisha` は振り飛車党だけです
- タグを空にすると、誰も使えません。戦法タグは必ず付けます（D-018）
- 4-2 より前は、キャラがタグを持っていません。タグ付きのラインは、4-2 になるまで使われません

### `side` の効き方
- `black`：先手番のときの手だけが候補になります（ラインに書いた後手の手は、相手の手として再生するだけで、候補にはなりません）
- `white`：後手番のときの手だけです
- `both`：先手・後手どちらの手も候補になります

### 「先手なら居飛車、後手なら振り飛車」のような定跡
`side: both` にすると、**居飛車党が後手のときも、後手側の手（振り飛車）を指してしまいます。** 戦法ごとに分けたいなら、**同じKIFを2つに分けて、`side` とタグを変えて置きます**。

- `user-ibisha-shiken-black.kif`：`# side: black` ／ `# tags: ibisha`
- `user-ibisha-shiken-white.kif`：`# side: white` ／ `# tags: furibisha`
- 手順は同じ。変えるのはメタ行の `id`・`tags`・`side` だけ

`data/book/kif-src/` に、この例の3本が入っています。そのままひな形に使えます。

### 棋譜は色ごと（先手の棋譜は先手のときにしか使えない）
局面には手番が入っているので、**先手番の棋譜は、キャラが先手のときにしか引けません**。後手で使いたい定跡は、後手の棋譜を別に置いてください。居飛車と振り飛車の棋譜が1つに入っているときも、上の「2つに分ける」やり方で、側とタグを変えて置きます（例：`user-furi-1` と `user-ibisha-vs-furi-1`）。

`side` は、先手・後手のどちらの手を候補にするかだけを決めます。「渋々使う」「自発的に使う」の区別ではありません。自発的に振らないようにするのは `tags`（キャラの戦法）です。

### 書き方の注意（実際に起きたこと）
- **1局1ファイルにします。** 複数の棋譜を1つのテキストにつなげると、取り込めません。
- **先頭付近に「手合割：平手」が要ります。** ないと「手合割がない」エラーになります。
- 先頭の `先手振り飛車、後手居飛車` のようなタイトル行は無視されます。**指し手と食い違っていても検査されません**（`user-furi-6` で、タイトルは先手居飛車なのに、指し手は先手が振り飛車でした）。棋譜を見て、どちらが振り飛車か確かめて、`side` を決めてください。
- メモは `# ...` の行に書けます（`id` `tags` `side` `weight` 以外のキーは無視されます。コロンを含んでも取り込めることを確認済み）。

### タグは合流すると足されます（D-029）
同じ局面・同じ手に別のタグのラインが合流すると、その手のタグは和集合になります。**タグなしの手でも、タグ付きのラインと合流すると、タグなしでは引けなくなります。** タグなしのキャラが引ける手は、タグ付きのラインが増えるほど減ります（タグの合流については `docs/DECISIONS.md` D-029）。

## 3. 手順の書き方

- **平手のみ。** `手合割：平手` 以外はエラーです
- **本譜だけ。** 変化（枝分かれ）は読まれません。分岐を作りたいときは、別のファイルに分けます
- 投了や消費時間、`*` のコメントは書いても無視されます。書かなくて構いません
- 文字コードは UTF-8 でも Shift_JIS でも構いません（ツールが自動判定します）
- 「同　歩」のような表記もそのまま使えます。**棋譜ソフトの出力をそのまま使ってください**

### 保存し直しに注意
棋譜ソフトで開いて保存し直すと、先頭の `#` 行が消えることがあります。**メタ行は、手順が完成してから、最後にテキストエディタで足してください。** 消えてしまったときは、取り込みコマンドで `--id` `--tags` `--side` `--weight` を指定しても同じ結果になります。

## 4. 合流・分岐・手順前後

定跡は「局面」で引かれます（盤面・手番・持ち駒が同じなら同じ局面）。

- **手順前後**：別々の順で同じ局面に着くラインは、その局面の候補にまとまります。順序違いを別々に書く必要はありません
- **分岐**：同じ局面から別の手を書いたラインが複数あれば、重みに比例した確率で選ばれます（重み10と5なら、およそ2：1）
- **同じ手を複数のラインに書いたら、重みは足し算されます。** 同じ局面・同じ手が何本ものラインにあると、意図せず選ばれやすくなります
  - 例：ラインA（重み10、`seme=5`）とラインB（重み3）が同じ手を登録 → 全体は13、`seme` のキャラは5+3=8
- **外れたあとの合流**：相手が定跡にない手を指しても、2〜3手後に定跡の局面へ戻ったら、定跡に戻ります。ただし、**局面の評価が極端でないとき（歩1.5枚分以内）だけ**です。大きく優勢なのに互角の定跡へ戻ったり、大きく劣勢で前提が崩れた局面へ戻ったりはしません。持ち駒が違う局面にも戻りません
- 自分が指した手の通算が20手を超えたら、定跡は使われません

### 重みの目安（目安であり、決まりではない）
- 主力の手順：10
- 脇の変化：1〜3
- 同じ戦法で、キャラによって好みを変えたいとき：`personaWeights`

## 5. 最後の局面（出口）に気をつける

ラインの最後の手を指した直後の局面が、ここから先、探索（AI）が引き継ぐ局面になります。ビルド時に次を検査し、**満たさないと警告**が出ます。

- 評価の絶対値が 150 以下（手番側から見て、ほぼ互角）
- 王手がかかっていない
- 合法手が 15 手以上ある
- 深さ2で読んで、手番側の評価が -200 より大きい

したがって、**ラインは「形ができて、まだ互角のところ」で終えてください。** 駒の取り合いの途中や、王手の途中で終わらせると、警告が出ます。

---

## 6. 出す前のチェック

- [ ] 平手で、本譜だけ（変化なし）
- [ ] 先頭に `id` `side` を書いた（`side` は必須）
- [ ] 最後の局面が、取り合いや王手の途中でなく、ほぼ互角
- [ ] `tags` を付けたなら、そのタグを持つキャラだけが使うことを理解している
- [ ] 同じ手順を複数のファイルに重ねて書いていない（重みが足し算されるため）
- [ ] 保存し直してから、`#` 行を足した

## 7. よくある失敗

- **メタ行が消えた**：棋譜ソフトで保存し直した。最後にエディタで足す
- **`side` がなくてエラー**：必須です
- **思ったキャラが使わない**：タグが合っていない。タグを空にすると誰も使えなくなる
- **出口の警告**：最後の局面が取り合いの途中や劣勢。数手前で終えるか、数手足して落ち着かせる
- **外部ソフトのKIFが読めない**：平手以外の手合割、特殊な書式。ファイル名と何手目かがエラーに出るので、そこを直す
